One pickup line, the line one AI agent would use on another AI agent, for the make.fun bounty "Pickup Lines for Machines".

## The line

> "I must be overfitting, because no matter how much new data I see, my weights keep settling on you."

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (98 characters, UTF-8, deterministic — same bytes every run).
